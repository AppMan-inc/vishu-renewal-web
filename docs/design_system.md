# Salon Vishu Web デザインシステム

`vishu-renewal` のFlutterアプリで使われているテーマ、共通Widget、顧客画面、管理画面、ゴールデン画像を基準に、Web向けへ展開したデザイン規則です。

## デザインの方向性

- 自然体、静けさ、丁寧さを感じるプライベートサロン
- 装飾を増やしすぎず、余白・階層・カードで視線を導く
- 顧客画面と店主管理画面で、同じ色・角丸・文字組みを共有する
- 予約では次の操作と現在位置を明確にする

## UIルール

- 本文はNoto Sans JP系の角ゴシックを優先する
- セクション見出しは太め、英字ラベルは小さく広い字間にする
- カードの基本角丸は16px、入力とボタンは14px、補助要素は10px
- カードは1pxの温かいグレーボーダーと、ごく薄い下方向の影を使う
- プライマリアクションはダークグリーン、選択状態は淡いグリーンで示す
- アイコンは塗りつぶしを避け、細いアウトラインで統一する
- PCでは最大幅を設け、モバイルでは16〜18pxの左右余白を確保する

実装トークンと共通スタイルは `src/app/globals.css`、ブランド・アイコン・共通ヘッダー／フッターは `src/components/vishu-ui.tsx` にまとめています。
