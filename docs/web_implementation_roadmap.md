## リリース判定

- 二重予約を防ぐ自動テストが成功している
- 権限のないユーザーが管理データを読書きできない
- 秘密情報がGit履歴やクライアントBundleに含まれない
- 予約完了と店主通知が実機で確認できる
- キャンセル、通知失敗、Firebase障害時の挙動が決まっている
