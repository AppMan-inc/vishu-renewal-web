# Vishu Renewal Web 残タスク

最終更新: 2026-08-27 JST

## 更新ルール

- このドキュメントを更新した場合は、必ず冒頭の「最終更新」を実際の更新日時（JST）に書き換える。

## 目的

公開サイト、Web予約、店主管理を、スマートフォン中心で実運用できるサービスに仕上げるための残タスクを整理する。

優先度は次の意味で使用する。

- `P0`: 予約運用や公開前に必須
- `P1`: 主要機能・主要画面として必要
- `P2`: 初回公開後でもよい追加改善

## 現状確認（2026-07-25時点）

| 項目 | 現状 | 残タスク |
| --- | --- | --- |
| 公開サイト | トップ、サロン紹介、メニュー抜粋、アクセス、予約導線が存在する | 実データ化、残りのページ、モバイル実機調整、SEOを仕上げる |
| Web予約 | メニュー、日時、お客様情報、確認、予約確定の基本フローが存在する | 本番予約ルール、履歴・キャンセル、通知、障害時対応を仕上げる |
| 管理者画面 | ログイン、ダッシュボード、予約、休憩、顧客・カルテ、メニューの基本画面が存在する | 本番権限、スマホ操作、運用機能、テストを仕上げる |
| 新規アカウント作成 | 未実装。ログインのみ | メール・Google・Appleの登録導線とプロフィール作成を実装する |
| メッセージ | 未実装 | アプリと共通データで管理者・ユーザー間メッセージを実装する |
| クーポン価格 | `beforePrice` と `afterPrice` のデータはあるが、予約画面は適用後価格だけを表示する | 適用前、適用後、割引内容を明示する |
| 絞り込み | 予約メニューのカテゴリ絞り込みは存在する | キーワード、価格、所要時間、空き状況等を追加する |
| 電話予約専用メニュー | 「要電話予約」は表示されるが、予約画面内に電話リンクがない | `tel:` のCTAと受付時間を表示する |
| スマホUI | レスポンシブCSSと一部固定アクションは存在する | スマホ実機を基準に全画面を再点検する |
